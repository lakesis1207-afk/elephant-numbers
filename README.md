# 코끼리와 숫자 친구들

만 3~5세 아이가 동물 친구들과 1부터 10까지 수를 익히는 가로형 웹 앱(PWA)입니다.
광고·결제·로그인이 없고, 진행 기록은 이 기기의 브라우저에만 저장됩니다.

## 들어 있는 것
- 마을 5곳, 게임 15개 (앞 마을 게임 3개를 끝내면 다음 마을이 열림)
  - 사바나(1~10): 반짝 무늬 보기, 과일 세기, 물웅덩이 채우기
  - 숲속(11~20): 풍선 터뜨리기(숫자 알아보기), 어느 쪽이 많아?, 도토리 세기
  - 바다·극지(10씩 100까지): 무늬 잇기, 물고기 묶기(묶음과 낱개), 열씩 세기
  - 공룡 나라(1~100): 숫자판 찾기, 발자국 빈칸, 알 더하기·빼기
  - 농장(복습): 달걀 바구니(더하기·빼기), 누가 더 많아?, 반짝 몇 개?
- 스티커(동물 34마리, 마을별 쪽) · 스티커북 · 특별 친구(유니콘)
- 아직 그림이 없는 동물 21마리는 자리 표시 그림(`npm run art:villages`로 만든 SVG)
- 하루 놀이 시간(기본 15분, 1분 전 알림, 잠금 화면) · 부모님 메뉴(자물쇠 3초 누르기)
- 홈 화면에 설치, 한 번 열면 인터넷 없이도 실행

## 개발
```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 규칙 자동 검사 (Vitest)
npm run test:e2e   # 브라우저 자동 검사 (Playwright: 개발 서버 + 빌드본)
npm run build      # dist/ 에 완성본
```

## 바꿔 끼우기
- **그림**: `public/images/` 안의 파일을 같은 이름으로 바꾸면 됩니다. 앱 아이콘은 코끼리 그림을 바꾼 뒤 `npm run icons`.
- **목소리**: Azure 음성(서현, 아이 목소리)으로 만들었습니다. 키를 환경 변수(`AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`)로 넣고 `npm run voice:azure`를 하면 아직 만들지 않은 문장만 `public/audio/voice/<파일 이름>.mp3`로 만듭니다(기록: 프로젝트 밖 `../녹음 원본/azure-done.json`). 녹음은 오프라인 저장본에도 들어갑니다. 대사를 바꾸면 `npm run voice:list`로 목록을 다시 만듭니다.

## 배포
`main` 브랜치에 올리면 GitHub Actions가 검사·빌드 후 GitHub Pages에 반영합니다
(저장소 Settings → Pages → Source를 "GitHub Actions"로 한 번 설정).
